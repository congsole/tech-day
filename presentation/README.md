# 겸상 — Reveal.js 발표 자료

`docs/presentation-plan.md`의 2026-11-05 개정안과 팀 경험 중심 표현 보완을 기준으로 전체 21장을 구현했습니다. 주제 선정부터 세 사람의 회고까지 구성안의 순서·핵심 메시지·사례를 유지합니다. 본편 21분 50초와 현장 여유 40초를 합쳐 약 22분 30초이며, 질의응답은 별도입니다.

## 실행 및 복사

`presentation` 폴더 전체를 다른 PC로 복사한 뒤 `index.html`을 Chrome 또는 Edge에서 여세요. HTML·CSS·JavaScript와 Reveal.js를 모두 로컬 파일로 포함했습니다. 빌드·npm 설치·인터넷 없이 실행하도록 구성했으며, 실행 중 Markdown 원본을 읽지 않으므로 이 폴더만 옮기면 됩니다.

브라우저에서 로컬 서버로 확인하고 싶다면 저장소 루트에서 다음 명령을 실행하고 `http://localhost:8765`를 여세요. 서버는 선택 사항입니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory presentation
```

- 오른쪽 화살표 / Space: 다음 요소 등장 → 다음 슬라이드
- 왼쪽 화살표: 이전 요소 / 슬라이드. 15·18·20장의 화면 변화도 이전 단계로 복원
- 화면 하단 ← / → 버튼: 마우스·터치로 동일한 순차 이동
- F: 전체 화면, Esc: 전체 보기
- S 또는 발표자 노트 버튼: 별도 노트 창. 팝업 차단 시 팝업 허용 후 다시 실행
- 노트 창: 이전·다음 버튼, 좌우 화살표·Space로 제어. 설명·출처·다음 제목·장별 시간·누적 계획 구간 표시

프로젝터에는 발표 화면만 표시하고, 노트 창은 발표자 화면에 두세요. 표기 시간은 계획 시간이며 자동 넘김이나 실시간 타이머가 아닙니다. 화면에서 회고의 화자·출처 표시는 빼고, 출처와 개인 의견의 범위는 노트에 남겼습니다. 작성·연출 주의사항과 회고 원문은 접힌 참고 항목으로 분리했습니다.

모바일에서는 가로 화면을 사용하세요. 파일 관리 앱의 HTML 미리보기는 JavaScript를 실행하지 않을 수 있으므로 브라우저로 열어야 합니다. PC의 파일 경로를 휴대폰에서 바로 열 수는 없습니다. 모바일 공유·접속에는 정적 호스팅 주소를 사용할 수 있습니다.

## 구현상 조정

기존 종이색 배경과 강조색, 타이포그래피를 유지하고 새 이야기의 화면 구성을 추가했습니다. 화면 문구는 가독성을 위해 줄바꿈하거나 짧게 표현했으며, 상세 설명과 근거는 발표자 노트에 담았습니다.

- 2장: 초기 아이디어는 같은 크기로 표시하고 겸상을 최종 선택으로 노출합니다. 사람별 아이디어의 규모를 비교하지 않습니다.
- 4·5·8장: 역할 조정, 합의 가능한 기획, 개인 맥락에만 남은 결정을 팀에서 있었던 일 중심으로 표시합니다. 이름은 역할 분담처럼 설명에 필요한 곳만 유지합니다.
- 11장: 논의·본업 복귀·PR 제출·승인 대기를 팀 전체의 경험을 요약한 도식으로 표현했습니다. 실접속 기록처럼 보이지 않도록 표시하고, 클릭마다 한 번만 짧은 등장 효과를 사용합니다.
- 12·16장: PR #104의 리뷰·수정 이력과 직접 사용하며 발견한 문제을 각각 표시합니다.
- 15장: 결함 재현 표가 등장할 때 앞의 관점 목록을 접어 공간을 확보합니다. 모의·실환경 검증 구분은 유지합니다.
- 18장: 머지 순서 설명 후 같은 장에서 #102 지적 → #115 첫 배포 → #117 수정 흐름으로 화면을 바꿉니다. 서로 다른 사건을 한 번에 빽빽하게 배치하지 않기 위한 조정입니다.
- 19장: 다섯 사례의 수정 결과와 남은 과제를 순차 노출합니다.
- 20장: 기획·규약, 운영 절차, 확인·판단 분담이라는 다음 방향을 순차 표시한 뒤 마지막 질문 화면으로 바꿉니다. 사건 경위는 18장에서 설명하고 여기서는 각자의 해석과 다음 선택에 집중합니다.

모든 전환은 발표자가 제어합니다. 자동 재생·반복 애니메이션·영상·영상 자리 표시자는 없습니다. OS의 모션 감소 설정에서는 CSS 전환과 애니메이션을 끕니다.

## 파일 구성과 오프라인 동작

- `index.html`: 21장 본문, 표준 `aside.notes` 발표자 노트, 근거 링크
- `style.css`: 1280×720(16:9) 화면, 타이포그래피·도식·순차 등장 스타일
- `app.js`: Reveal 초기화, 터치 버튼, 발표자 노트 동기화, 단계별 화면 복원
- `vendor/reveal.js`, `vendor/reveal.css`: Reveal.js 5.2.1
- `vendor/LICENSE`: Reveal.js MIT 라이선스

외부 CDN·웹폰트·이미지 요청, 런타임 파일 가져오기, ES 모듈 로딩을 사용하지 않습니다. 외부 근거·앱 링크는 사용자가 누를 때만 접속합니다. 시스템 한글 글꼴을 사용하므로 PC별 글꼴 모양은 다를 수 있습니다.

파일 직접 실행을 위해 별도 발표자 노트 창을 사용합니다. Reveal.js 기본 노트 플러그인 대신 로컬 스크립트로 창을 동기화하며, 다음 슬라이드는 제목으로 표시합니다.
