# 겸상 — Reveal.js 발표 자료

`docs/presentation-plan.md`의 2026-11-04 개정안을 기준으로 전체 11장을 구현했습니다. 순서와 핵심 메시지를 유지하며, 장별 예상 시간은 35·40·45·45·45·45·70·90·60·65·30초입니다. 본편 9분 30초에 현장 여유 30초를 더한 구성입니다.

## 실행 및 복사

`presentation` 폴더 전체를 복사한 뒤 `index.html`을 Chrome 또는 Edge에서 여세요. HTML·CSS·JavaScript와 Reveal.js를 모두 로컬 파일로 포함해, 빌드·npm 설치·인터넷·서버 없이 실행하도록 구성했습니다. 실행 시 Markdown 원본은 읽지 않으므로 이 폴더만 옮기면 됩니다.

- 오른쪽 화살표 / Space: 다음 요소 등장 → 다음 슬라이드
- 왼쪽 화살표: 이전 요소 / 슬라이드
- 화면 하단 ← / → 버튼: 마우스·터치로 동일한 순차 이동
- F: 전체 화면, Esc: 전체 보기
- S 또는 발표자 노트 버튼: 별도 노트 창. 팝업 차단 시 해당 파일의 팝업 허용 후 다시 실행
- 노트 창: 이전·다음 버튼, 좌우 화살표·Space로 제어. 노트·출처 링크·다음 제목·장별 시간·누적 계획 구간 표시

프로젝터에는 발표 화면만 표시하고, 노트 창은 발표자 화면에 두세요. 표기한 시간은 계획 시간이며 자동 넘김이나 실시간 타이머가 아닙니다.

모바일에서는 파일 관리 앱의 HTML 미리보기가 JavaScript를 실행하지 않을 수 있습니다. 전체 폴더를 브라우저가 읽을 수 있는 환경에서 열고 가로 화면을 사용하세요. PC의 로컬 파일 경로를 휴대폰에서 바로 열 수는 없습니다. 모바일 실기기 동작은 미검증입니다.

## 파일 구성

- `index.html`: 11장 본문, 표준 `aside.notes` 발표자 노트, 근거 링크
- `style.css`: 1280×720(16:9) 화면, 타이포그래피·도식·순차 등장 스타일
- `app.js`: Reveal 초기화, 터치 버튼, 발표자 노트 동기화, 8장 단계별 레이아웃
- `vendor/reveal.js`, `vendor/reveal.css`: Reveal.js 5.2.1
- `vendor/LICENSE`: Reveal.js MIT 라이선스

외부 CDN·웹폰트·이미지·영상 요청 없이 동작합니다. 외부 링크는 사용자가 누를 때만 접속합니다. 시스템 한글 글꼴을 사용하므로 PC별 글꼴 모양은 다를 수 있습니다.

## 개정안 반영과 구현상 조정

- 3장: 역할 표를 제거하고 Claude Code·Codex가 하나의 `AGENTS.md`를 공유하는 도식으로 변경
- 4장: 문서 PR → 요구사항 이슈 → 구현 PR의 3단계 흐름으로 변경
- 5·6장: 기능 분담의 선택 이유, 같은 검토자와 사람의 승인 지점 설명 분리
- 7장: 개별 참여 여부 조회와 상위 공유 데이터 전달을 전후 도식으로 비교
- 8장: 누락·실제 수정·개선 제안을 순서대로 표시한 뒤 결함 재현 표 등장. 이때 앞의 관점 목록을 접고 제목을 줄여 밀도 조절. 뒤로 이동하면 원래 상태 복구
- 9·10장: PR 선행 조건과 공통 확인 절차를 구분하고, 실제 적용·개선 제안의 상태를 글자로 명시
- 11장: 함께 검토할 대상과 PR 통합 순서에 관한 수정 질문 반영

구성안의 제목은 가독성을 위해 일부 줄바꿈하며 순서는 유지합니다. 전환은 짧은 페이드 중심이고, 순차 노출은 사용자가 제어합니다. 모션 감소 설정에서는 CSS 애니메이션·전환을 끕니다.

파일 직접 실행을 위해 별도 발표자 노트 창을 사용합니다. Reveal.js 기본 노트 플러그인은 로컬 서버를 요구하므로 채택하지 않았습니다. 노트의 다음 슬라이드는 제목으로 표시합니다.
