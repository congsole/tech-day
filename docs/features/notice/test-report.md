## 2. REQ-NOTICE-02 집합/수령 장소 (#46)

- 검증일: 2026-10-29
- 기준: `dev` 44bc8e7(PR #95 머지)을 합친 `feature/notice-place`, PR #98
- 환경: 사용자 로컬 앱(`npm run dev`)과 실제 Supabase

| 항목 | 방법 | 결과 |
|---|---|---|
| 정적 검사 | `npm run lint`, 타입 검사 | 통과 |
| 수정 저장 | Host 계정, 모집중 겸상에서 장소 수정 | 바뀐 장소 표시 |
| 다른 탭 반영 | 같은 겸상을 연 다른 탭 | 새로 고침 없이 반영 (#81 `meals` 수정 구독) |
| 빈 값 | 빈 값·공백만 입력 후 저장 | 저장 차단, 안내 표시 |
| 유형별 라벨 | 식사·배달 겸상 | `집합 장소`·`수령 장소` |
| 수정 버튼 표시 | Host가 아닌 겸상, 모집중이 아닌 겸상 | 미표시 |

### 검증 한계

- Host가 아닌 사용자의 직접 수정 요청과 모집중이 아닌 겸상의 수정 요청은 화면에서 보낼 수 없어 서버 차단·안내 문구를 실환경에서 재현하지 않음. `updatePlace`는 RLS로 막힌 수정을 0행으로 판단해 `모집중일 때만 장소를 수정할 수 있습니다.`를 표시한다.
- 첫 다른 탭 확인은 병합 중 dev 서버 다시 불러오기 실패로 이전 코드가 떠 있어 반영되지 않았고, 새로 고침 후 통과.
