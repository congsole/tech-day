# 인증 + 겸상 열기 + 목록 화면 설계

담당: wgmin0416. 요구사항은 `docs/features/meal/requirements.md`, 공통 표현은 `docs/common/design-system.md`를 따른다.

### SCR-MEAL-LOGIN 로그인
- 경로: `/login`
- 관련 요구사항: REQ-MEAL-01
- 진입: 로그인하지 않은 사용자가 로그인이 필요한 화면에 들어오면 이 화면으로 이동한다. 원래 가려던 화면을 기억한다.
- 구성: 카드 하나에 화면 제목 "겸상 로그인"과 단계별 입력
- 1단계 이메일 입력
  - 안내 문구: 사내 이메일로 인증 코드를 보낸다는 안내
  - 이메일 입력창과 "인증 코드 받기" 버튼
  - 이메일이 비어 있거나 발송에 실패하면 이메일 입력창 아래에 안내
- 2단계 코드 입력
  - 안내 문구: 코드를 보낸 이메일 주소 표시
  - "인증 코드" 라벨과 6칸 숫자 입력. 각 칸의 접근성 이름은 "인증 코드"
  - 제출: 6칸을 모두 채우는 순간 자동 제출한다. "로그인" 버튼으로도 제출할 수 있다 (자동 제출이 실패한 뒤 다시 제출하는 경우 등)
  - 6자리가 안 되면 제출하지 않고 안내. 코드가 틀렸거나 만료되면 코드 입력 아래에 안내하고 2단계에 머문다
  - "이메일 다시 입력" 버튼(보조 행동)을 누르면 1단계로 돌아간다
- 완료: 로그인되면 기억한 화면으로, 없으면 `/`로 이동한다
