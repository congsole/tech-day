# 인증 + 겸상 열기 + 목록 테스트 결과서

요구사항은 `docs/features/meal/requirements.md`, 화면은 `docs/features/meal/screen.md`를 기준으로 한다.
결과: 통과 / 실패 / 미실시. 미실시는 사유를 적는다.

## REQ-MEAL-04 모집중 겸상 목록 보기
- 확인일: 2026-10-26
- 환경: 로컬 개발 서버(`npm run dev`), 공용 Supabase 프로젝트, 수동 확인

| 항목 | 기준 | 결과 | 비고 |
|---|---|---|---|
| 카드 표시 | 인수 조건 2: 제목·유형·현재 인원/정원 표시 | 통과 | 공용 DB의 기존 모집중 겸상으로 확인 |
| 상세 이동 | SCR-MEAL-LIST: 카드를 누르면 `/meals/:id`로 이동 | 통과 | |
| 취소 겸상 제외 | 인수 조건 1: 취소 상태 미노출 | 미실시 | 취소 겸상을 만들 기능(REQ-MEAL-03 겸상 열기, REQ-MEAL-06 겸상 취소) 구현 전 |
| 주문중 이후 겸상 제외 | 인수 조건 1: 주문중·주문완료·정산 상태 미노출 | 미실시 | 주문중 전환에 필요한 메뉴 입력(REQ-JOIN-02) 구현 전 |
| 빈 목록 안내 | SCR-MEAL-LIST: "모집중인 겸상이 없습니다." 표시 | 미실시 | 공용 DB에 다른 팀원의 모집중 겸상이 있어 빈 목록 상태를 만들 수 없음 |
