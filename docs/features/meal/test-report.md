## REQ-MEAL-06 겸상 취소 (Host)
- 확인일: 2026-10-27
- 환경: 로컬 개발 서버(`npm run dev`), 공용 Supabase 프로젝트, 수동 확인. 모바일(48em 미만)·데스크톱 폭

| 항목 | 기준 | 결과 | 비고 |
|---|---|---|---|
| Host 취소 | 인수 조건 1: 사유를 적고 취소하면 상태가 취소 | 통과 | 상세에 머물며 배지 취소, 취소 사유 표시, 취소 버튼 사라짐 |
| Host가 아닌 사용자 화면 | 인수 조건 2: Host가 아니면 취소 동작 없음 | 통과 | 다른 사람이 연 겸상 상세에 취소 버튼 미표시 |

| 목록 제외 | 인수 조건 3: 취소된 겸상은 모집중 목록에서 제외 | 통과 | |
| 빈 사유 | 인수 조건 4: 사유가 비었거나 공백만이면 취소되지 않고 안내 | 통과 | |
| 대화상자 | SCR-MEAL-CANCEL: 열 때 사유 입력 포커스, 돌아가기·바깥 누르기·Esc로 닫으면 입력 초기화 | 통과 | |
| 모바일 폭 | SCR-MEAL-CANCEL: 대화상자·버튼이 화면 안, 터치 영역 | 통과 | |
| 상세 보는 중 시간 경과 | SCR-MEAL-INFO: 주문 예정 시간이 되면 새로 고침 없이 Host 관리 동작 숨김 | 통과 | 2026-10-28 재확인. #71 리뷰 반영 |
| 대화상자 열린 채 시간 경과 | SCR-MEAL-CANCEL: 입력 유지, 겸상 취소 버튼 비활성, 모집중 안내 | 통과 | 2026-10-28 재확인. 닫은 뒤 버튼 미표시 |
